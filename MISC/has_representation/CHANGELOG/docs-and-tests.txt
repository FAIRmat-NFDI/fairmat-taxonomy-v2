CHANGELOG -- examples, tests and documentation
===============================================

Examples
--------
Added 18 independent Turtle ABoxes:
- valid optional-unit case for every representation;
- invalid supplied-unit case for every representation;
- invalid missing-quantity-kind case for every representation.

The six valid ABoxes now contain scientist-readable sample data, explicit
material-property links, and multi-observation profile/image/volume fixtures.

examples-TBOX/ was intentionally skipped.

Tests
-----
Added test/representation_test.py. It checks:
- Turtle and SHACL execution;
- declared versus actual result codes;
- expected conformance status;
- observation completeness;
- canonical QUDT ranges;
- absence of class-level skos:closeMatch;
- RDF Data Cube subclass bridges;
- absence of locally defined order semantics.

The runner regenerates test/reports.md.
