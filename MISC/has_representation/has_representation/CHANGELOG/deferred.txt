DEFERRED SEMANTIC DECISIONS
===========================

The following items were deliberately not changed in this revision:

1. Canonical unit assertions
   The existing rep:hasUnit statements on rep:x, rep:energy and the other
   canonical components remain. No default, fallback, inheritance, precedence,
   or override rule is defined.

2. Rank semantics
   Rank 0/1/2/3 still defines Scalar/Profile/Image/VolumeData. A future design
   may separate structural rank classes from scientific interpretation.

3. Representation cardinality
   rep:has_representation and its typed subproperties remain functional.

4. Structural SHACL
   Axis membership, axis count, rank agreement, extents, observation
   uniqueness, numerical datatypes and full Data Cube integrity constraints
   remain outside the unit-only shapes graph.

5. Scientific unit semantics
   The present table is an application whitelist. Dimension vectors,
   convertibility, affine units, calibrated signals, unit conversion and
   scientific compatibility need a separate design.
